# oganessian2010 — Oganessian (2010)

*Reading note, 20 Nov 2026. Up: [references](../README.md). Record: `references/sources.json`, id `oganessian2010`; graph node `ref-oganessian-2010-synthesis-new-element`.*

**Source.** Oganessian, Yu. Ts.; Abdullin, F. Sh.; Bailey, P. D.; Benker, D. E.; et al. (33 authors). Synthesis of a New Element with Atomic Number Z = 117. Physical Review Letters 104 : 142502.
DOI [10.1103/PhysRevLett.104.142502](https://doi.org/10.1103/PhysRevLett.104.142502).

**What was read.** abstract only (INSPIRE-HEP record of the DOI); the paper is paywalled; the 220 ms value is quoted from NUBASE2020, which cites this paper.

**Design and sample.** Discovery experiment for element 117 (48Ca on 249Bk) at the Dubna separator. The abstract reports decay chains 'involving 11 new nuclei'; the number of chains is NOT FOUND in the abstract.

## What the source says

- "The isotopes 293-117 and 294-117 were produced in fusion reactions between 48Ca and 249Bk." (abstract).
- "The measured decay properties show a strong rise of stability for heavier isotopes with Z≥111, validating the concept of the long sought island of enhanced stability for superheavy nuclei." (abstract).
- NUBASE2020 (p. 030001-179) lists the first half-life measured for 289Mc from this paper: "10Og01=220(+260-80)" ms.

## What the ASRP text says about it

- `bob-lazar-archive/analysis/MASTER_technical_claims.md:154` — "Lab-synthesized 115 (Darmstadt/Dubna, ~220 ms half-life) is the unstable isotope" (summary of a 2019 podcast statement).

## Verdict

**matches**

A 220 ms value for an isotope of element 115 exists in the literature: it is the 2010 first value for 289Mc, with an uncertainty of +260/−80 ms. It is one isotope's early value, not 'the' half-life of element 115; the current evaluated values run from 20 ms (286Mc) to about 0.65–0.84 s (290Mc). The attribution to Darmstadt is the speaker's, not the paper's: this measurement is from Dubna.
