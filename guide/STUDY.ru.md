## Что это за исследование

Этот репозиторий — **Хаб реверс-инжиниринга**: многотрековая исследовательская программа, координирующая несколько параллельных направлений изучения явлений класса НАЯ. Хаб организует первичные наблюдательные архивы, методологические слои и кросс-архивный синтез в единую навигируемую структуру.

Исследование артефакта **UAP-FRAG-001** (трёхконвейерное: ИИ / архивный / Расширенное Когнитивное Восприятие) — **один** из этих треков, Трек 1. Он идёт параллельно с историческими архивами (Боб Лазар, Вадим Чернобров, Дубна / Элемент 115), методологическим слоем (OSINT и разведывательный анализ), кластером людей (дело 11 учёных, консолидированное ФБР 19.04.2026), запланированным слоем корпоративного / экономического анализа и корневым кросс-архивным синтезом.

*Примечание к прочтению.* Дата консолидации ФБР (19.04.2026) повторена в репозитории по пересказу одного автора на YouTube; здесь её следует считать непроверенной ([Открытые вопросы](OPEN.ru.md)).

Прежний README был единым навигационным хабом, где история каждого трека лежала на одной странице; теперь титульная страница разбита на короткие страницы (см. [Навигация и структура](NAVIGATION.ru.md)), а прежний README сохранён байт в байт в [`archive/`](../archive/README_2026-11-19_pre-showcase.md). У каждого трека по-прежнему есть свой README с полным первичным материалом.

**Какой вопрос ставится.** Можно ли изучать необычный объект, сочетая отчёты перципиентов, машинное зрение и архивы, и какие нарративы о происхождении НАЯ выдерживают фильтр доказательств?

**Коротко, что это.** Приватный поисковый исследовательский хаб из <!--n:tracks-->11<!--/n--> треков и <!--n:files_ru-->1517 файлов<!--/n--> под учётом git. Единственный эксперимент: один сеанс Расширенного Когнитивного Восприятия (КП) по одному объекту, `UAP-FRAG-001`: <!--n:percipient_reports-->3<!--/n--> перципиента описали его до того, как их ответы сравнили с раскрытым позже референсом из <!--n:ref_params-->10<!--/n--> параметров. <!--n:ref_exact-->7<!--/n--> из <!--n:ref_params-->10<!--/n--> параметров совпали точно, но отчёт самого исследования говорит, что эти числа не показывают независимой конвергенции, потому что ослепление нарушено у <!--n:blinded_compromised_n-->2<!--/n--> из <!--n:percipient_reports-->3<!--/n--> перципиентов. Остальные десять треков: курируемые архивы публичного материала (свидетельства, интервью, рассекреченные записи, литература) и методологический слой; они фиксируют заявления, не валидируя их.

## Чем это не является

- **Не валидированный результат.** Всё предварительно; об этом говорит собственная оговорка исследования (см. [Этика](ETHICS.ru.md#отказ-от-ответственности)).
- **Не запатентованный метод.** Заявки на патент по этому исследованию нет; патенты, названные в репозитории, принадлежат родственным исследованиям или являются сторонними патентами, которые изучаются ([Экосистема](ECOSYSTEM.ru.md#связь-с-патентом)).
- **Не предрегистрировано.** Статус предварительной регистрации OSF: «Уточняется», ID не записан ([Экосистема](ECOSYSTEM.ru.md#предварительная-регистрация-osf)).
- **Не читаемый курс.** Курс по НАЯ описан как разрабатываемый; он не запущен ([Экосистема](ECOSYSTEM.ru.md#образовательная-программа-и-модель-коммерциализации)).
- **Не вердикт по архивам.** Лазар, Чернобров, интервью ОИЯИ, Герштейн и релизы PURSUE записаны как заявления или внешние записи, а не как проверенные факты ([Доказательства](EVIDENCE.ru.md)).

### Группа ВСКЧ

Группа ВСКЧ (перципиенты с высокой когнитивной и сенсорной чувствительностью), задействованные в протоколах психометрического считывания информации с объектов.

В единственном записанном сеансе участвовали три перципиента. Их имена на этих страницах не приводятся (PII, memory-policy); первичные отчёты в репозитории доступны из [трека 1](EXPERIMENT.ru.md).
