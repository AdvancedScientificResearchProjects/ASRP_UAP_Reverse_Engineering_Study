# The study: what this hub is

</div>

## What this study is

This repository is a **Reverse Engineering Hub** — a multi-track research program coordinating several parallel investigations into UAP-class phenomena. The hub organizes primary observational archives, methodology layers, and cross-archive synthesis into a single navigable structure.

The artifact investigation around fragment **UAP-FRAG-001** (3-pipeline study: AI / archival / Extended Cognitive Perception) is **one** of these tracks — Track 1. It runs in parallel with historical archives (Bob Lazar, Vadim Chernobrov, Dubna / Element 115), a methodology layer (OSINT + Intelligence Analysis), a people-analysis cluster (the 11 scientists case consolidated by the FBI on 2026-04-19), a planned corporate / economic analysis layer, and the root-level cross-archive synthesis.

*Reading note.* The FBI consolidation date (2026-04-19) is repeated in the repository from a single-author YouTube recap; treat it as unverified here ([Open questions](OPEN.md)).

The README of this repository used to be a single navigation hub with every track's story on one page; that front page is now split into short pages (see [Navigation and structure](NAVIGATION.md)) and the previous README is kept byte for byte in [`archive/`](../archive/README_2026-11-19_pre-showcase.md). Each track still has its own README with the full primary material.

**The question it asks.** Can an unusual object be studied by combining percipient reports, machine vision and archives, and which UAP origin narratives survive an evidence filter?

**What it is, in short.** An exploratory research hub of <!--n:tracks-->11<!--/n--> tracks and <!--n:files_total-->1517<!--/n--> tracked files. Its one experiment is a single Extended Cognitive Perception (ECP) session on one object, `UAP-FRAG-001`: <!--n:percipient_reports-->3<!--/n--> percipients described it before a later-disclosed <!--n:ref_params-->10<!--/n-->-parameter reference was compared with their answers. <!--n:ref_exact-->7<!--/n--> of <!--n:ref_params-->10<!--/n--> parameters match exactly, but the study's own report says the counts do not show independent convergence, because blinding was compromised for <!--n:blinded_compromised_n-->2<!--/n--> of <!--n:percipient_reports-->3<!--/n--> percipients. The other ten tracks are curated archives of public material (testimony, interviews, declassified records, literature) and a methodology layer; they record claims without validating them.

## What it is not

- **Not a validated finding.** Everything is preliminary; the study's own disclaimer says so (see [Ethics](ETHICS.md#disclaimer)).
- **Not a patented method.** There is no patent filing for this study; the patents named in the repository belong to sibling studies or are third-party patents under study ([Ecosystem](ECOSYSTEM.md#patent-connection)).
- **Not preregistered.** The OSF preregistration status reads "To be determined" and no ID is recorded ([Ecosystem](ECOSYSTEM.md#osf-preregistration)).
- **Not a taught course.** A UAP course is described as in development; the repository does not claim it is live ([Ecosystem](ECOSYSTEM.md#educational-program-and-the-commercialization-model)).
- **Not a verdict on the archives.** Lazar, Chernobrov, the JINR interview, Gershtein and the PURSUE releases are recorded as claims or as external records, not as verified facts ([Evidence](EVIDENCE.md)).
